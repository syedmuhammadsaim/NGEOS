========================================================================
             NGEOS - NGO & CHARITY PLATFORM DESKTOP APPLICATION
========================================================================

NGEOS can be run and installed as a Desktop Application in 2 easy ways:

METHOD 1: ONE-CLICK DESKTOP SHORTCUT (FOR YOU & LOCAL USERS)
------------------------------------------------------------------------
1. Double-click the "NGEOS" shortcut on your Desktop (or "Run-NGEOS-Desktop.bat").
2. It automatically starts the backend server in the background and opens NGEOS 
   in an official frameless Native Desktop App Window.
3. No browser address bars or tabs - pure desktop app experience!


METHOD 2: DIRECT BROWSER PWA INSTALL (TO SHARE WITH ANYONE ONLINE/OFFLINE)
------------------------------------------------------------------------
1. Open NGEOS in Microsoft Edge or Google Chrome (http://localhost:5000 or your live URL).
2. You will see a yellow "Install App" button in the navigation bar (or the ⊞ / (+) icon 
   at the right end of the address bar).
3. Click "Install App" -> Confirm "Install".
4. Windows will automatically install NGEOS onto your Desktop, Taskbar, and Start Menu!
5. Now you can launch NGEOS like any desktop program anytime.


SHARING WITH OTHERS:
------------------------------------------------------------------------
- Option A (Recommended for web): Deploy the site to any web host (e.g. IIS, Azure, Render).
  Send the link to anyone; they click "Install App" in their browser, and it installs 
  instantly on their Windows PC or Mac.
- Option B (Offline Zip Package): Zip the "publish" folder and share it with someone.
  They only need to extract it and double-click "Run-NGEOS-Desktop.bat".
